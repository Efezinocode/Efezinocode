## 🤖 PassSabi AI

**PassSabi AI** is a student-focused AI learning platform that I founded.

The idea is simple:

**Make learning easier and more accessible by putting an AI-powered learning companion in students' hands.**

I'm building PassSabi AI to help students understand difficult concepts, ask questions, learn interactively, and use modern AI technology as part of their education.

Building PassSabi has pushed me far beyond basic programming.

I've had to learn about:

- Authentication
- Databases
- APIs
- AI integration
- Supabase
- Vercel
- GitHub

And I'm still learning.
