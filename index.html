About me

Building with purpose.

My journey started with programming fundamentals and grew into a bigger ambition: using technology to solve real problems.

I don't want to only use technology. I want to build it.

I'm Uzezi Great Efezino, a developer from Nigeria focused on Python, web development, AI and product building.

I started by learning programming fundamentals and building small projects. Those projects taught me something important: the best way to learn technology is to actually build with it.

That mindset eventually led me to create PassSabi AI, a student-focused AI learning platform that I'm building to make learning more interactive and accessible.
